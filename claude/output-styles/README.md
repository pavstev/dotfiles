# Output styles

[Output styles](https://docs.claude.com/en/docs/claude-code/output-styles) adjust
Claude Code's system prompt/tone. Each `name.md` has YAML frontmatter (`name`,
`description`) and a body describing the behavior. Activate with `/output-style <name>`
or set `"outputStyle"` in `settings.json`.

Symlinked to `~/.claude/output-styles` by `./dotfiles`. See `concise.md`.
